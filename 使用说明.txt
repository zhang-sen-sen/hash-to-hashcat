========================================================
  一键转 Hash 工具（绿色单文件版）使用说明
========================================================

一、这是干什么的
  把【加密的】Office 文档、PDF、ZIP、RAR、7Z 压缩包，
  转成 hashcat / hashcatGUI 可以直接加载的哈希行（.hash.txt），
  之后你在 hashcatGUI 里选好模式号，配置字典或掩码，就能 GPU 爆破密码。

二、怎么用（30 秒上手）
  1) 把要破解的文件【拖到「转Hash工具.exe」图标上】松手，
     等黑色窗口跑完；一次可以拖多个文件。
  2) 每个文件旁边会生成同名「.hash.txt」，里面就是哈希行。
  3) 打开 hashcatGUI：
     - 哈希类型填下方表格里的模式号
     - 哈希文件选刚生成的 .hash.txt
     - 攻击方式选「字典」或「掩码」，配置好后开跑

三、本工具不需要装任何东西
  - 不需要安装 Python
  - 不需要安装任何库（PDF 转换所需的解析能力已内置）
  - 单个 21MB 的 exe，整个文件夹拷到 U 盘、别的电脑都能直接用

四、支持的文件类型与 hashcat 模式号
  格式                    哈希前缀      hashcat -m    备注
  ---------------------------------------------------------------
  .docx/.doc/.xls/.xlsx     $office$      9400        Office 2007+ AES
  .ppt/.pptx                $office$      9600        旧版 RC4 一般用 9600
  .pdf                      $pdf$        10400/10500  不同 PDF 版本自动区分
                                         10600/10700
  .zip (ZipCrypto)          $pkzip$       17200
  .zip (AES)                $zip2$/$zip3$ 17220-17225
  .rar (RAR5)               $rar5$       13000
  .rar (RAR3 -hp 文件头密)  $RAR3$       12500
  .rar (RAR3 仅文件名密)    $RAR3$       23700/23800
  .7z                       $7z$         11600

  注：GUI 里模式号不一定完全等于上面的 -m 值，以你用的
      hashcatGUI 界面选项为准（通常写的是 hashcat 模式号）。

五、常见问题
  1) 提示"未产出哈希行" → 文件没有加密，或者加密方式不在此范围。
  2) 7z 固实压缩（多个文件压成一坨）也能产出行，但部分
     hashcat 版本无法校验该行（能加载但不命中），这是 hashcat
     模块的限制，不是行错误；非固实、单文件的 7z 都正常。
  3) .hash.txt 千万别用记事本手动改名保存，记事本会加 BOM 导致
     hashcat 报 "Byte Order Mark detected"；直接用本工具生成的文件。

六、目录文件
  转Hash工具.exe   绿色主程序（拖文件到它上面即可）
  转Hash.bat       备用启动器（双击后输入路径，或把文件拖到 bat 上）
  使用说明.txt      本文件
  tohash.py / office2john.py / pdf2john.py / zip2john.py / rar2john.py / 7z2john.py
                    源码（供自行修改；日常使用只需 exe）
